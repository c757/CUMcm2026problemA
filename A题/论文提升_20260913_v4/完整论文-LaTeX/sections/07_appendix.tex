本次使用Python 3.10.12。先按依赖清单安装所需包，再准备文泉驿正黑TrueType字体：Linux可安装发行版的\texttt{fonts-wqy-zenhei}，也可把原版\texttt{wqy-zenhei.ttc}置于项目的\texttt{assets/}目录。字体不是计算过程中自动联网下载的隐含资源。Python依赖、原始输入和字体准备完成后，从项目根目录执行：
\begin{Verbatim}[fontsize=\small,breaklines,breakanywhere]
python3 -m pip install -r requirements.txt
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python3 -B reproduce.py
\end{Verbatim}

该命令在项目内新建\texttt{reproduced\_*}目录，从原始附件副本重新执行移动域解析检验、四问完整计算、网格及时间精度复验、全过程工作簿、六张题表、场数组、情景对照和14组图，不覆盖现有结果。某一步失败即返回非零退出码。快速回归和独立基准可分别执行：
\begin{Verbatim}[fontsize=\small,breaklines,breakanywhere]
python3 -B reproduce.py --smoke
python3 -B verify_moving_domain.py
python3 -B verify_moving_domain.py --mutant-only
\end{Verbatim}

最后一条命令故意使用错误几何算子，预期以非零退出码拒绝；不能将该预期失败与正式完整入口失败混同。快速回归仅覆盖600秒，不替代完整复现。问题二正式范围始终为全干燥过程逐秒输出，开发用前三小时选项不是本文交付范围。工作簿体积较大，因此采用分块采样和流式压缩写入，避免同时在内存中保存全部单元格对象。

论文在LaTeX工程内以XeLaTeX编译两遍，无需shell escape或外部BibTeX。需准备ctex、fvextra、常用数学和表格宏包，以及Noto Serif/Sans CJK SC字体。论文中图使用已嵌入TrueType字体的矢量PDF，代码副本仅用于阅读和来源核对；实际数值命令应从包含原始附件的项目根目录运行。公开支撑压缩包保留全部数值、图和源码，但不重复打包字体二进制、主论文PDF及本机临时文件；字体应按上述方法准备，主论文单独交付。
