原计算使用Python 3.10.12，依赖版本见`requirements.txt`。先准备项目虚拟环境及依赖；绘图另需文泉驿正黑字体`wqy-zenhei.ttc`，按许可放入`assets/`。支撑包保留字体许可，不重复包含字体二进制，程序不自动下载或安装依赖。

从包含附件的项目根目录执行：

`OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python3 -B reproduce.py`

完整入口创建`reproduced_*`输出目录，执行移动域基准、四问计算、精度比较、工作簿导出和绘图，保留原有结果。单独检查可执行：

- `python3 -B verify_moving_domain.py --mutant-only`：故意冻结几何因子的对照，预期退出1，正常检查成功退出0。

以上是完整代码提供的复现方法。本次编辑未重新执行完整数值求解，沿用已有真实结果与验证记录。
