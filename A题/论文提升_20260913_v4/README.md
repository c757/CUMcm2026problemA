## 数值复现

原计算环境为 Python 3.10.12，包版本见 `requirements.txt`。使用者可自行准备项目虚拟环境并安装这些依赖；本次仅恢复文档编译与检查环境，未更改系统 Python。绘图还需文泉驿正黑字体，可按字体许可准备 `wqy-zenhei.ttc` 并放入 `assets/`。支撑包保留字体许可，不包含字体二进制，程序不自动下载字体或安装依赖。

依赖和字体准备好后，从包含附件的项目根目录执行：

```bash
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python3 -B reproduce.py
```

完整入口新建 `reproduced_*` 目录，执行移动域基准、四问计算、精度检验、工作簿导出和绘图，不覆盖已有结果。快速检查命令为：

```bash

python3 -B verify_moving_domain.py --mutant-only
```

最后一条是故意固定几何因子的对照，预期退出1；其余成功退出0。600秒快速检查只覆盖短过程，完整复现使用第一条完整入口。

## 论文编译

分别进入 `完整论文-LaTeX/` 和 `AI工具说明-LaTeX/`，执行两遍：

```bash
xelatex -no-shell-escape -interaction=nonstopmode -halt-on-error main.tex
```

需要 ctex、fvextra、常用数学与表格宏包，以及 Noto Serif/Sans CJK SC 字体。文献为随文条目，无需 BibTeX。源码采用相对路径，数值复现与论文编译相互独立。

当前服务器恢复的 TeX 工具、PDF 检查依赖及缓存全部位于本项目的隐藏 `.work/` 目录；未执行系统级安装，不装入支撑压缩包。内部检查记录与构建前恢复快照也在该目录中。
