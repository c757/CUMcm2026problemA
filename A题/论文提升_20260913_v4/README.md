## 数值复现

本次核验环境为Python 3.10.12，依赖见`requirements.txt`。需要文泉驿正黑字体，可准备发行版的`fonts-wqy-zenhei`，或将原版`wqy-zenhei.ttc`放入`assets/`。支撑压缩包保留字体许可但不含字体二进制；程序不自动下载字体或安装依赖。以下安装命令供使用者自行准备隔离环境，本轮未修改系统Python。

```bash
python3 -m pip install -r requirements.txt
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python3 -B reproduce.py
```

完整入口在项目下新建`reproduced_*`目录，执行移动域基准、四问计算、精度检查、全过程工作簿、图形和运行记录，不覆盖现有结果。快速检查：

```bash
python3 -B reproduce.py --smoke
python3 -B verify_moving_domain.py
python3 -B verify_moving_domain.py --mutant-only
```

最后一条故意使用错误算子，预期退出码为1；其余命令成功应退出0。600秒回归不能替代完整求解。当前`results/`保留原运行来源，本次复制不是新一次全量计算。
