# 统一术语

| 符号或表述 | 本文定义 | 不应混用 |
|---|---|---|
| 一维径向场 | 轴向和周向均匀，允许沿径向变化 | 径向均匀场 |
| C | 干基含水率，kg水/kg干固体 | 空气含湿量、当前体积水浓度 |
| W_a、C_e | 原始空气记录、有效边界输入；定义C_e=W_a | 真实气固平衡含水率 |
| theta、T | 摄氏温度、绝对温度T=theta+273.15 K | Arrhenius指数中的摄氏温度 |
| rho_h、A_h | 热容量经验参数、A_h=rho_h c_p | 实际湿体密度、完整混合物储能 |
| rho_d | 当前单位体积干固体质量 | rho_h |
| r、R(t)、x | 物理半径坐标、表面半径、随体坐标r/R | 固定输出点与材料点 |
| Cbar | 2∫xC dx，等于干质量加权平均 | 无权节点平均、R²Cbar |
| t*、t*,N、ts | 连续模型阈值时刻、数值事件、下一严格整秒 | 亚秒误差保证 |
| *_sampled | 明确时间及径向采样网格上的统计值 | 连续全时空极值 |
| 归一化水分平衡 | Cbar+Lambda=2.55的数值自洽检查 | 独立实验准确率 |
| 几何对照 | 保持问题四物性，仅固定半径为2 cm | 问题三和问题四的总差异 |

控制方程、物性与全部公设见同目录《题目分析报告.md》。
